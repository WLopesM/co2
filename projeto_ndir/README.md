# Projeto NDIR headspace

Medição quantitativa do CO₂ dissolvido por um sensor NDIR de faixa 0–5%. O sensor lê o ar de um equilibrador instalado no sump. É independente do projeto Drop Checker óptico e serve para **comparar os resultados** dos dois métodos.

**Status:** planejamento. Ver [docs/fase-00-planejamento.md](docs/fase-00-planejamento.md).

O projeto começa depois que o Drop Checker óptico chegar à fase 3 (monitoramento), para que a comparação tenha uma referência já funcionando.
